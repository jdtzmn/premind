# Unsubscribe with Premind

Use the `mcp__plugin_premind_premind__unsubscribe` tool to remove the requested pull-request subscription from the current Claude Code session. The plugin binds the operation to this session through Claude Code's `CLAUDE_CODE_SESSION_ID`; do not request or supply a session ID.
